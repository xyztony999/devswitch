## 第一部分：文档概述

将业务架构（BA）映射为应用域、功能模块、功能子模块的层级结构，标注用户类型与模块调用关系。本次新增 Android SDK 纳管能力，落在既有"运行时扫描/下载/切换"模块内的 androidsdk 维度扩展。

### 1.1 背景与目标

Go 2.0 单文件实现（CLI + GUI 同体）。应用架构描述功能的组织方式，为功能清单（FL）与模块级 PRD/API 设计提供结构基线。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 业务→功能映射，应用域分层（DDD 四层）、用户类型、调用关系 |
| 本文档不做什么 | 不涉及功能点细节、不涉及接口定义与技术实现 |

### 1.3 范围

| 范围 | 说明 |
|------|------|
| 业务域 | 开发工具链版本管理 |
| 应用域 | 核心业务域 / 支撑业务域 / 基础数据域 / 平台支撑域 |
| 用户类型 | 开发者（本机用户，单一角色） |

## 第二部分：应用架构

### 本架构概览

核心价值在"环境切换"（用户级 shim + HOME 变量即时生效）；扫描/导入/下载为核心提供版本候选；治理能力（共享/诊断）维持一致性。工具注册表承载五类工具的元数据（shim 名单/HOME 变量/下载源/检测器）。平台支撑域提供 CLI/GUI/更新检查/补全/分发等技术载体。

### 应用域分层

| 分层 | 说明 | 包含功能模块 |
|------|------|-------------|
| 核心业务域 | 承载核心价值，深度建模 | C-01 环境切换、C-02 会话即时生效 |
| 支撑业务域 | 为核心提供业务支撑 | S-01 运行时扫描、S-02 手动导入、S-03 运行时下载、S-04 版本选择共享、S-05 环境诊断 |
| 基础数据域 | 系统级引用数据 | D-01 工具注册表 |
| 平台支撑域 | 纯技术能力 | P-01 CLI 命令行、P-02 图形界面、P-03 新版本检查、P-04 shell 补全、P-05 安装包分发 |

### 2.1 核心业务域

**应用域概述**：产品差异化所在——无管理员权限的用户级版本切换与会话即时生效机制。

#### 2.1.1 C-01 环境切换

**功能说明**：将某工具的指定安装设为当前版本：重写该工具全部 shim 并维护 HOME 环境变量（node/npm、java/javac、mvn、gradle、adb/fastboot）。

**涉及用户类型**：- [✓] 开发者

##### 2.1.1.1 shim 接管

**功能说明**：在 shim 目录生成/清除命令入口；Windows 双写 .cmd + sh twin；未选中的工具不留桩（保持 command not found 语义）。

**涉及用户类型**：- [✓] 开发者

**调用关系**：

| 调用模块/子模块 | 调用说明 |
|---------------|---------|
| D-01 工具注册表 | 读取各工具 shim 名单（androidsdk → adb/fastboot） |

##### 2.1.1.2 HOME 环境变量生效

**功能说明**：写用户环境变量（JAVA_HOME/MAVEN_HOME/GRADLE_HOME/ANDROID_HOME）并广播；Android SDK 额外把 platform-tools 纳入会话 PATH。

**涉及用户类型**：- [✓] 开发者

**调用关系**：

| 调用模块/子模块 | 调用说明 |
|---------------|---------|
| D-01 工具注册表 | 读取工具→HOME 变量名映射（androidsdk → ANDROID_HOME） |

#### 2.1.2 C-02 会话即时生效

**功能说明**：切换后已打开终端立即使用新版本。

**涉及用户类型**：- [✓] 开发者

##### 2.1.2.1 shell 钩子

**功能说明**：bashrc/.profile（Linux）、PowerShell profile 与 Git Bash bashrc（Windows）注入/移除钩子。

**涉及用户类型**：- [✓] 开发者

##### 2.1.2.2 会话内 PATH 前置

**功能说明**：shim 执行时定位 current.env；应用进程自身同步前置 shim 目录。

**涉及用户类型**：- [✓] 开发者

### 2.2 支撑业务域

**应用域概述**：为核心切换提供版本候选（扫描/导入/下载）与环境一致性（共享/诊断）。

#### 2.2.1 S-01 运行时扫描

**功能说明**：无子进程探测本机安装（读 release 文件/jar 元数据/目录名/注册表卸载表）。

**涉及用户类型**：- [✓] 开发者

##### 2.2.1.1 Node.js 检测
**功能说明**：解压版目录名、nvm-windows/scoop 布局。
**涉及用户类型**：- [✓] 开发者
**调用关系**：D-01 工具注册表（检测器分发）

##### 2.2.1.2 Java 检测
**功能说明**：各厂商 JDK 目录与 release 文件版本解析。
**涉及用户类型**：- [✓] 开发者
**调用关系**：D-01 工具注册表（检测器分发）

##### 2.2.1.3 Maven/Gradle 检测
**功能说明**：解压目录 + lib jar 文件名解析版本。
**涉及用户类型**：- [✓] 开发者
**调用关系**：D-01 工具注册表（检测器分发）

##### 2.2.1.4 Android SDK 检测
**功能说明**：Android Studio 默认目录（%LOCALAPPDATA%\Android\Sdk / ~/Android/Sdk）、ANDROID_HOME/ANDROID_SDK_ROOT 环境变量指向、PATH 中 adb 回溯；识别 platform-tools 版本（adb 元数据）与 build-tools 列表。
**涉及用户类型**：- [✓] 开发者
**调用关系**：D-01 工具注册表（检测器分发）

#### 2.2.2 S-02 手动导入

**功能说明**：目录导入并校验版本元数据。
**涉及用户类型**：- [✓] 开发者

##### 2.2.2.1 目录导入与校验
**功能说明**：五类工具统一导入入口；Android SDK 校验 platform-tools/ 子目录与 adb 存在性。
**涉及用户类型**：- [✓] 开发者
**调用关系**：S-01 运行时扫描（复用检测器校验）

#### 2.2.3 S-03 运行时下载

**功能说明**：下载安装指定大版本并切换；URL 白名单 + 哈希校验 + 安全解压。
**涉及用户类型**：- [✓] 开发者

##### 2.2.3.1 官方源下载
**功能说明**：Node/Java/Maven/Gradle 官方地址；Android SDK 走 dl.google.com。
**涉及用户类型**：- [✓] 开发者
**调用关系**：C-01 环境切换（装完即切）

##### 2.2.3.2 国内镜像下载
**功能说明**：npmmirror/清华源；Android SDK 走腾讯 AndroidSDK 镜像（mirrors.cloud.tencent.com/AndroidSDK/）。
**涉及用户类型**：- [✓] 开发者
**调用关系**：C-01 环境切换（装完即切）

#### 2.2.4 S-04 版本选择共享

**功能说明**：.devswitch 文件的导出与对齐。
**涉及用户类型**：- [✓] 开发者

##### 2.2.4.1 版本选择导出
**功能说明**：导出五工具当前选择（androidsdk 记 platform-tools 版本）。
**涉及用户类型**：- [✓] 开发者

##### 2.2.4.2 按文件对齐
**功能说明**：对齐本机版本，--install-missing 自动下载缺项。
**涉及用户类型**：- [✓] 开发者
**调用关系**：S-03 运行时下载（缺项触发）、C-01 环境切换（对齐即切）

#### 2.2.5 S-05 环境诊断

**功能说明**：冲突检测与一键修复。
**涉及用户类型**：- [✓] 开发者

##### 2.2.5.1 冲突检测
**功能说明**：会话/用户 PATH 顺序、HOME 变量一致性（含 ANDROID_HOME）、shim 缺失（含 adb）、钩子缺失。
**涉及用户类型**：- [✓] 开发者

##### 2.2.5.2 一键修复
**功能说明**：后台重建全部生效物 + 进程 PATH 同步 + 注释冲突手写行。
**涉及用户类型**：- [✓] 开发者
**调用关系**：C-01 环境切换、C-02 会话即时生效（重建生效物）

### 2.3 基础数据域

**应用域概述**：系统级引用数据，读远大于写，无状态机。

#### 2.3.1 D-01 工具注册表

**功能说明**：五类工具的元数据注册：工具标识（node/java/maven/gradle/androidsdk）、显示名、shim 名单、HOME 变量名、检测器、下载源与镜像清单。新增 androidsdk 项为本次变更核心。

**涉及用户类型**：- [✓] 开发者

### 2.4 平台支撑域

**应用域概述**：纯技术载体与通用能力，无本领域业务规则。

#### 2.4.1 P-01 CLI 命令行
**功能说明**：scan/list/current/use/install/import/export/apply/which/doctor/cleanup/update/completion 子命令入口。
**涉及用户类型**：- [✓] 开发者

#### 2.4.2 P-02 图形界面
**功能说明**：WebView2/WebKit 窗口 + 托盘 + 通知；左侧导航（五工具 + 诊断 + 关于）。
**涉及用户类型**：- [✓] 开发者

#### 2.4.3 P-03 新版本检查
**功能说明**：只读查询 GitHub latest release 并提示。
**涉及用户类型**：- [✓] 开发者

#### 2.4.4 P-04 shell 补全
**功能说明**：bash/zsh/powershell 补全脚本输出。
**涉及用户类型**：- [✓] 开发者

#### 2.4.5 P-05 安装包分发
**功能说明**：六平台产物（Windows x64/arm64 安装器与便携 zip、deb/rpm ×2、Linux tar ×2）。
**涉及用户类型**：- [✓] 开发者
