## 第一部分：文档概述

DevSwitch 是跨 Windows/Linux 的开发工具链版本管理器，管理 Node.js / Java / Maven / Gradle（现有）与 Android SDK（本次新增）的本机安装。本业务架构描述产品覆盖的业务域、业务阶段与关键业务能力，作为应用架构与功能清单的上游基线。

### 1.1 背景与目标

多套运行时共存时（解压版 Node、多厂商 JDK、多个 SDK 目录），PATH 冲突与版本漂移是高频痛点。DevSwitch 以用户级 shim + 环境变量 + shell 钩子的方式，在不触碰系统目录、不需要管理员权限的前提下，实现"扫描收拢、一键切换、已开终端即时生效"。本次新增 Android SDK 纳管，使安卓开发者（adb/fastboot、ANDROID_HOME）获得同体验。

## 第二部分：业务架构

### 本架构概览

用户旅程呈三段：先把本机已有的运行时**纳管**进清单（扫描/导入/下载），再通过**切换**选定当前版本（shim 与环境变量即时生效），并以**治理**能力维持环境健康（团队对齐、冲突诊断）。

### 2.1 运行时纳管

**业务说明**：发现并收拢本机的工具链安装，形成统一版本清单。覆盖四类现有工具与 Android SDK。

##### 2.1.1 运行时扫描

**业务说明**：自动检测本机各工具的已有安装。所属 L2：运行时纳管。

###### 2.1.1.1 Node.js 环境检测

**业务说明**：检测解压版 node-v*、nvm-windows/scoop 等来源的 Node.js 安装。所属 L3：运行时扫描。

###### 2.1.1.2 Java 环境检测

**业务说明**：检测各厂商 JDK（Oracle/Temurin/Microsoft/Zulu/Corretto 等）与系统安装。所属 L3：运行时扫描。

###### 2.1.1.3 Maven 与 Gradle 环境检测

**业务说明**：检测本机 Maven/Gradle 分发包（元数据解析，无子进程探测）。所属 L3：运行时扫描。

###### 2.1.1.4 Android SDK 环境检测

**业务说明**：检测 Android Studio 默认目录（%LOCALAPPDATA%\Android\Sdk、~/Android/Sdk）、ANDROID_HOME/ANDROID_SDK_ROOT 指向的 SDK 与手动导入的 SDK 根目录；识别 platform-tools 版本（adb 版本）。所属 L3：运行时扫描。

##### 2.1.2 手动导入

**业务说明**：对扫描覆盖不到的安装位置，由用户指定目录导入并校验有效性。所属 L2：运行时纳管。

###### 2.1.2.1 目录导入与校验

**业务说明**：指定工具安装目录，校验其版本元数据后纳入清单（五类工具同一体验，Android SDK 校验 platform-tools 子目录存在性）。所属 L3：手动导入。

##### 2.1.3 运行时下载

**业务说明**：直接下载安装指定大版本并切换，支持国内镜像加速。所属 L2：运行时纳管。


##### 2.1.4 运行时移除

**业务说明**：把某个已纳管的版本从清单摘除，可选磁盘卸载。所属 L2：运行时纳管。

###### 2.1.4.1 移出版本清单

**业务说明**：按版本或安装目录定位实例，从版本清单移除；激活中的版本须先切换。所属 L3：运行时移除。

###### 2.1.4.2 磁盘卸载

**业务说明**：确认后删除该版本的磁盘目录。红线：仅限用户主目录内、外来安装（系统/环境变量/PATH 发现）永不动盘、删除前二次确认完整路径。所属 L3：运行时移除。

###### 2.1.3.1 官方源下载

**业务说明**：从官方发布地址下载（Node/Java/Maven/Gradle；Android SDK 官方 dl.google.com）。所属 L3：运行时下载。

###### 2.1.3.2 国内镜像下载

**业务说明**：经 npmmirror/清华源（现有四工具）与腾讯 AndroidSDK 镜像（Android SDK）下载。所属 L3：运行时下载。

### 2.2 版本切换

**业务说明**：产品的核心价值——选定当前版本并即时生效。

##### 2.2.1 环境切换

**业务说明**：把某工具的某个安装设为当前版本。所属 L2：版本切换。

###### 2.2.1.1 shim 接管

**业务说明**：用户 PATH 前置目录生成命令入口（node/npm、java/javac、mvn、gradle，Android SDK 为 adb/fastboot），未选中的工具不留桩。所属 L3：环境切换。

###### 2.2.1.2 HOME 环境变量生效

**业务说明**：维护 JAVA_HOME/MAVEN_HOME/GRADLE_HOME/ANDROID_HOME 指向当前版本（Windows 用户环境变量 + 广播；Linux 钩子导出）。所属 L3：环境切换。

##### 2.2.2 会话即时生效

**业务说明**：切换后已打开的终端立即使用新版本，无需重开。所属 L2：版本切换。

###### 2.2.2.1 shell 钩子

**业务说明**：bashrc/.profile（Linux）与 PowerShell profile、Git Bash bashrc（Windows）注入钩子，会话内前置 shim 目录与导出 HOME 变量。所属 L3：会话即时生效。

###### 2.2.2.2 会话内 PATH 前置

**业务说明**：shim 机制使新命令解析即走新版本；本机进程内同步 PATH（含 GUI 自身）。所属 L3：会话即时生效。

### 2.3 版本治理

**业务说明**：维持团队与本机环境的健康与一致。

##### 2.3.1 版本选择共享

**业务说明**：以 .devswitch 文件共享团队版本选择。所属 L2：版本治理。

###### 2.3.1.1 版本选择导出

**业务说明**：导出当前各工具选择到 .devswitch（可提交进仓库）。所属 L3：版本选择共享。

###### 2.3.1.2 按文件对齐

**业务说明**：按 .devswitch 对齐本机版本，缺少的版本可选自动下载。所属 L3：版本选择共享。

##### 2.3.2 环境诊断

**业务说明**：检查 PATH/shim/钩子/环境变量冲突并修复。所属 L2：版本治理。

###### 2.3.2.1 冲突检测

**业务说明**：检测会话 PATH 顺序、用户 PATH 注册表、HOME 变量一致性、shim 缺失/被篡改、钩子缺失（Android SDK 增补 ANDROID_HOME 一致性与 adb shim 检查）。所属 L3：环境诊断。

###### 2.3.2.2 一键修复

**业务说明**：重建全部生效物（shim/钩子/环境变量/进程 PATH）并注释冲突手写行。所属 L3：环境诊断。

### 附录B：业务术语表

| 术语 | 定义 | 备注 |
|------|------|------|
| shim | 用户 PATH 目录中的命令入口，执行时定位当前选中版本 | Windows 双写 .cmd + sh |
| platform-tools | Android SDK 组件，含 adb/fastboot | 版本独立于 SDK 整体更新 |
| ANDROID_HOME | 指向 SDK 根目录的环境变量 | 旧名 ANDROID_SDK_ROOT |
| .devswitch | 团队版本选择共享文件 | export/apply 成对 |
