# DevSwitch 功能清单

## 第一部分：文档概述

按用户类型分章列出可操作的菜单与功能点，作为功能开发与验收的依据。本次变更：开发者章节新增 Android SDK 相关菜单（扫描结果维度、下载入口、切换项、导入校验、诊断项）。

### 1.1 背景与目标

DevSwitch 单用户本机工具，功能清单按"开发者"单一用户类型组织。

### 1.2 文档定位

| 定位 | 说明 |
|------|------|
| 本文档做什么 | 按用户类型列出菜单与功能点描述 |
| 本文档不做什么 | 不涉及技术实现、数据库设计、接口定义 |

### 1.3 范围

| 范围 | 说明 |
|------|------|
| 业务域 | 开发工具链版本管理 |
| 用户类型 | 开发者 |

## 第二部分：功能清单

### 本清单概览

开发者覆盖全部应用域；核心操作集中在环境切换（C-01）与运行时纳管（S-01~S-03）。Android SDK 作为第五工具融入既有菜单结构。

## 2.1 开发者

**用户类型概述**：本机开发环境的唯一使用者，通过 CLI 或 GUI 完成工具链的纳管、切换与治理。

#### 2.1.1 核心业务域

**应用域概述**：版本切换核心能力。

##### 2.1.1.1 C-01 环境切换

**功能说明**：设定当前版本并生成生效物。

###### shim 接管

**功能说明**：命令入口生成与清除。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 切换版本 | `devswitch use <tool> <ver>` / GUI 卡片"切换到此版本"；androidsdk 同用法 | shim 接管 | adb/fastboot 入口 |
| 启动器生成 | 应用自身命令入口（devswitch/devswitch-gui）随切换重建 | shim 接管 | |

###### HOME 环境变量生效

**功能说明**：用户环境变量维护。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 查看当前版本 | `devswitch current` 列出五工具激活项（含 ANDROID_HOME 指向） | HOME 环境变量生效 | |
| 查询实际二进制 | `devswitch which adb` 打印当前真实路径 | HOME 环境变量生效 | 新增 adb 支持 |

##### 2.1.1.2 C-02 会话即时生效

**功能说明**：已开终端即时使用新版本。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 重新扫描 | CLI/GUI 触发，重建生效物并刷新列表 | 会话内 PATH 前置 | |
| 项目环境输出 | `devswitch env-project`：读 .devswitch/.nvmrc 输出会话级 export 语句 | 项目级自动切换 | v1.2 |
| 自动切换钩子 | shell 钩子自动 eval（PROMPT_COMMAND，会话级不写全局） | 项目级自动切换 | v1.2 |

#### 2.1.2 支撑业务域

**应用域概述**：版本候选供给与环境治理。

##### 2.1.2.1 S-01 运行时扫描

**功能说明**：本机安装检测。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 版本列表 | `devswitch list [tool]`（GUI 左导航五工具页）；androidsdk 页列出 SDK 实例与 platform-tools 版本 | Android SDK 检测等 | |
| 扫描本机 | `devswitch scan`；Android SDK 检测 AS 默认目录/ANDROID_HOME/PATH 回溯 | Android SDK 检测 | |

##### 2.1.2.2 S-02 手动导入

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 导入目录 | CLI `devswitch import androidsdk <path>` / GUI 文件夹对话框；校验 platform-tools 子目录 | 目录导入与校验 | |

##### 2.1.2.3 S-03 运行时下载

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 下载安装 | `devswitch install androidsdk [ver] --mirror tencent` / GUI 下载条；下载 cmdline-tools+platform-tools 解压至用户目录并切换 | 国内镜像下载 | 默认官方源 |
| 下载 Go | `devswitch install golang <ver>`（golang.google.cn 清单解析）；GOROOT 指向新装的 ~/go-<ver> | 国内镜像下载 | v1.2 |
| 下载 Python | `devswitch install python <ver>`（python-build-standalone via npmmirror）；完整 CPython 含 pip | 国内镜像下载 | v1.2 |

##### 2.1.2.6 S-06 运行时移除

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 移除版本 | `devswitch remove <tool> <ver\|home>`；激活中阻止 | 移出版本清单 | |
| 磁盘卸载 | `--purge`：红线三查后删目录（二次确认 / 仅用户目录 / 外来安装不动盘） | 磁盘卸载 | |
| 卡片移除 | GUI 版本卡片「移除」按钮 + 确认层（可勾选同时删磁盘） | 移出版本清单 | v1.1 |

##### 2.1.2.4 S-04 版本选择共享

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 导出选择 | `devswitch export` 写 .devswitch（含 androidsdk） | 版本选择导出 | |
| 按文件对齐 | `devswitch apply .devswitch [--install-missing]` | 按文件对齐 | |

##### 2.1.2.5 S-05 环境诊断

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 环境诊断 | `devswitch doctor` / GUI 诊断页；含 ANDROID_HOME 一致性与 adb shim 检查 | 冲突检测 | |
| 一键修复 | `devswitch doctor --fix` / GUI 按钮（后台执行） | 一键修复 | |

#### 2.1.3 平台支撑域

**应用域概述**：技术载体（不展开为业务菜单）。

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 图形界面 | 左导航五工具+诊断+关于；托盘菜单切换 | P-02 图形界面 | androidsdk 页新增 |
| 检查更新 | 启动静默 + 关于页手动检查 | P-03 新版本检查 | |
| shell 补全 | `devswitch completion bash/zsh/powershell` | P-04 shell 补全 | |
| 清理配置 | `devswitch cleanup` 卸载配套 | P-01 CLI 命令行 | |
