# 设计文档：UI 响应式重建（小窗口适配）

| 属性 | 值 |
|------|-----|
| 版本 | v1.0（发布 v2.3.2） |
| D0 决策 | 顶栏渐进折叠 + 侧栏响应式抽屉（均推荐项） |

## 问题

窗口收窄后：7 个 top-chips 换行挤成两行、顶栏高度失控、品牌/扫描按钮被挤压——当前布局对宽度没有断点设计。

## 方案（两断点 + 折叠组件）

### 断点

| 宽度 | 布局 |
|------|------|
| ≥1100px | 现状（全量 chips + 常驻侧栏） |
| 769–1099px | chips 折叠为「当前激活 ▾」下拉；侧栏常驻但收窄（208→64px 图标栏：只显 logo+版本数字） |
| ≤768px | 抽屉：侧栏隐藏，顶栏汉堡按钮开关（遮罩层）；主区占满 |

### 组件/实现

- `TopChips.vue`：容器宽度 ResizeObserver（<1100px 渲染 NDropdown 单钮：当前工具名+版本，点开列七工具）；≥1100px 渲染全量 chips
- `SideNav.vue`：从 MainLayout 抽出；props `collapsed`（中宽）/`drawerOpen`（窄宽，遮罩点击关闭）；≤768px fixed 定位滑入滑出
- MainLayout 壳加 `window.innerWidth` 响应式断点状态（resize 监听 + 初始值）；汉堡按钮 ≤768px 显示
- 微调：顶栏高度固定 54px 不再被内容撑开；chips 单行 overflow hidden

### 验收（Gate 2）

- CDP 三宽度回归：1366（全量）/900（折叠+图标栏）/640（抽屉）——断言 chips 形态、侧栏定位、抽屉开关、七工具页仍可达
- 截图三宽度存档；功能流（切换/移除）不受影响

## Gate 1 自检

纯前端响应式；无新接口/聚合；风险（断点抖动）由 ResizeObserver 单点状态规避。**PASS**
